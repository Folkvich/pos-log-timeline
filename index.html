POS Log Timeline

รวม log ทุกตัวเป็นเส้นเวลาเดียว หาจุดผิดปกติ (log หาย, error, ข้อความแจ้งเตือน) จุด restart และสรุปส่ง Dev ไฟล์ทั้งหมดอ่านในเครื่องคุณ ไม่ถูกส่งออกไปไหน
ล้างข้อมูลที่โหลดไว้? ไฟล์ log ทั้งหมดจะถูกเอาออกจากหน้านี้ (ไฟล์ในเครื่องไม่ถูกลบ)

ภาพรวมการเขียน log

แท่ง = จำนวนบรรทัด log (สูง = เขียนถี่) ช่วงที่ log หลักหาย (กดเพื่อซูมดู) Restart มี ERROR / FATAL ช่วงที่กำลังดู (แถบบนสุด)
วิธีใช้: คลิก บนกราฟ = เปิด Timeline ที่เวลานั้น · ลากซ้าย–ขวา = ซูมเฉพาะช่วงที่ลาก · คลิกแถบบนสุด = เลื่อนไปดูช่วงนั้น · ดับเบิลคลิก = ดูทั้งหมด

Timeline รวม

ช่วงเวลา ถึง
คลิกบรรทัดเพื่อดูข้อความเต็ม · ตัวหนา = บรรทัดสำคัญ · พื้นส้ม = คำที่ไฮไลต์ · แถบเขียว = restart · แถบแดง = error

Library เคส

      
    

    
คู่มือแต่ละหัวข้ออาการ แยกตามกลุ่มสาเหตุ พร้อมเคสจริงที่บันทึกไว้ กด "บันทึกเข้า Library" ในการ์ดจุดผิดปกติเพื่อเก็บเคส (จำไว้ในเบราว์เซอร์นี้)

    

      

      
      
    

    

    

      แชร์ Library กับทีม
      

        
        
        
      

      
    

  


  

    

      จัดการหัวข้ออาการและกลุ่มสาเหตุ
      
หัวข้อ 0–13 มีกฎในระบบอยู่แล้ว แก้ชื่อและกลุ่มได้ หัวข้อที่เพิ่มเองจะถูกเลือกเมื่อพบ "คำค้นใน log" ในช่วงก่อนค้าง (ใส่หลายคำคั่นด้วย | ได้) และใส่คำค้นเพิ่มให้หัวข้อเดิมก็ได้

      

        

          
#ชื่อหัวข้อกลุ่มสาเหตุคำค้นใน log (ไม่บังคับ)ค้นใน log
